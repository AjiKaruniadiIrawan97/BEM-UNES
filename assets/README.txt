Struktur aset situs Halo Advo / SIAP
====================================

assets/hero/     Gambar latar carousel beranda (slide-1 … slide-3).
                  Baca assets/hero/README.txt untuk cara mengganti foto.

assets/images/   Opsional: taruh gambar konten lain di sini (poster, dll.)
                  lalu rujuk dari HTML dengan url('assets/images/nama-file.jpg').
