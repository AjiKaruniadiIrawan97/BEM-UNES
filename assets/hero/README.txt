Folder hero carousel — Halo Advo / SIAP
========================================

File lokal: slide-1.png (dan slide-2.png, slide-3.png jika Anda punya tiga foto).

Di index.html, slide 1 memakai assets/hero/slide-1.png. Slide 2–3 bisa
menggunakan URL demo (picsum) agar transisi carousel terlihat — ganti ke
url('assets/hero/slide-2.png') dll. jika ingin semua offline.

Kekuatan tint merah di atas foto: sunting .hero-overlay di styles.css
(alpha rgba — angka lebih kecil = foto lebih terlihat).

File slide-1.svg … slide-3.svg (jika masih ada) adalah cadangan grafis vektor;
boleh dihapus jika sudah memakai foto PNG/JPG.
